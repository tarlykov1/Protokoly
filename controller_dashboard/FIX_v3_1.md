# Исправление пустого кабинета контролёра v3.1

**Диагноз подтверждён на фактическом кэше, выгруженном 27.10.2026:** 3349 строк участников, 331 уникальное поручение после дедупликации по `task_id`, у двух поручений `deadline` отсутствует. В `bitrix/controller-dashboard/dashboard.html` версии v3 условие `body.items.every(... /^\\d{4}-\\d{2}-\\d{2}$/.test(x.due||'') ...)` отклоняло весь ответ, если хотя бы одна задача без срока.

Патч v3.1:
- В `loadApi()` допускается `x.due === ''` наряду с `YYYY-MM-DD`; контролируется целостность остальных полей.
- `diff()` возвращает `null` для неизвестной даты, а не `NaN`.
- `status()` не классифицирует задачу с неизвестным сроком как просроченную.
- Сортировка использует `a.due || '9999-12-31'` и аналогично `b.due`.
- В реестре выводится `Срок не указан` и `Без срока`.
- Ошибки PHP-прокси выводятся с текстом `detail`, чтобы различать 403/503 и дефект формата данных.

**Порядок установки:** заменить только `/home/bitrix/www/controller-dashboard/dashboard.html` версией v3.1 из пакета, предварительно сохранив резервную копию. FastAPI и PHP обработчики не меняются, рестарт не нужен; затем Ctrl+F5.

**Состояние Git:** это диагностическая документация к патчу; бинарный ZIP и весь HTML по-прежнему предоставлены отдельно, а не закоммичены как исходник. Убедиться после установки, что HTTP 200 у `/controller-dashboard/api.php?path=items`; если API 403/503 — отдельно проверить серверный секрет и прокси, не отключая защиту.
