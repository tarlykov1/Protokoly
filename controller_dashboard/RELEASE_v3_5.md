# Кабинет контролёра – v3.5 (27.10.2026)

После обратной связи контролёра исправлены ранее пропущенные требования. Установочный комплект: `controller_dashboard_v3_5.zip` (отдельное вложение в разговоре).

## Реализовано в установочном ZIP
- Время последней выгрузки (`generated_at`)
- Отдельный фильтр исполнителя с учётом соисполнителей
- Доля исполненных в срок вместо дублирующего KPI «Актуальных»
- Линейная динамика числа закрытых поручений, периоды неделя/месяц/квартал/год
- Просроченные в разрезе реальных стадий канбана, срок сегодня, ждёт контроля, возвраты, наличие комментария контролёра
- Колонки соисполнителей, помощников, руководителя задачи (`leader_id`, когда заполнен)
- Отображение отсутствующего срока без ошибки

## Не выдавать за реализованное
- Непрочитанный/новый комментарий **со времени просмотра**: хранить per-user view timestamps
- Руководитель по оргструктуре: отдельная интеграция с сотрудниками/структурой
- 7 рабочих дней без активности: официальный производственный календарь РФ
- Достоверная история повторных переносов: Bitrix task history API
- Протоколы: добавить второй источник
- Изменение блока «Требует внимания» **в самом стабильном дашборде МЕМО**: отдельное безопасное изменение
- Метрика 48 рабочих часов требует сверки `reaction_work_minutes` с событием начала, иначе не использовать как окончательный норматив

## Порядок установки
Заменять только `dashboard.html` и `dashboard.js` на сервере Битрикс24 и `memo_adapter.py` на Python-сервере после резервного копирования. Перезапускать только `bitrix-dashboards` после проверки синтаксиса. Не трогать `main.py`, `api.php`, `config.php`, секреты и действующие модули.

**Важно:** сам ZIP пока не загружен в GitHub и full-source не закоммичен; это запись версионного статуса, а не заместитель исходников. Для воспроизводимого Git-релиза нужно перенести исходники из ZIP и проверить соответствие SHA256 из MANIFEST. PR остаётся draft.
