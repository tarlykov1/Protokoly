# Снапшот Python-сервера от 27.10.2026

Источник: присланная выгрузка `app(1).zip`, 402 элемента, включая рабочие файлы, логи, отчёты и кэш.

## Рабочие точки входа

- `main.py`: основное FastAPI-приложение, подключение `protocol_dashboard.router`, `create_memo_activity_dashboard_router(fast_bitrix)`, `create_pptx_report_router(fast_bitrix)` и установленного `controller_dashboard`.
- `memo_activity_dashboard.py`: API `/memo-activity-dashboard-api/{data,status,build,export.xlsx,...}`, веб-страница `/memo-activity-dashboard`; аналитика участников МЕМО; работает с `data/memo_activity_cache.json`.
- `protocol_dashboard/router.py`: API `/protocol-dashboard-api/{health,meta,...}`; backend ожидает защищённую пару заголовков `X-Dashboard-Token` и `X-Bitrix-User`, которую должен формировать **только PHP-прокси**.
- `controller_dashboard/router.py`: текущий черновик, подключён в `main.py`. Прямые маршруты выдают 503 до подключения проверенного PHP-прокси.
- HTML-шаблоны лежат в `templates/`; пользовательская точка входа PHP на стороне Битрикс24 изучена отдельно в `docs/bitrix24-dashboard-existing-architecture.md`.

## Обнаруженная проблема безопасности

В присланной версии `protocol_dashboard/settings.py` присутствует **жёстко прописанное значение по умолчанию для API-токена**. Не публиковать этот файл как есть. Установить секрет исключительно через переменную окружения `PROTOCOL_DASHBOARD_TOKEN` (без дефолтного значения), убедиться в конфигурации службы и PHP-прокси и **заменить ранее использованный токен**, если он мог быть раскрыт. Нельзя отключать проверку заголовка без надёжной замены. Сам секрет здесь намеренно не приведён.

## Дальнейшая интеграция

Использовать рабочую схему `PHP index.php + api.php (prolog_before.php, $USER->IsAuthorized(), проверка групп) → FastAPI` и не вводить локальное OAuth-приложение только ради нового кабинета. Проверять разрешения на уровне групп до выдачи JSON, а backend заголовки принимать только при действительном серверном секрете и ограничении сетевого доступа. Режим 503 до завершения проверки сохраняется.
